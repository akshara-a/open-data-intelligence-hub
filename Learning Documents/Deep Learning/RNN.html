MISSION 01 / THE PROBLEM

Why would a neural network need memory?

Some information only makes sense when you remember what came before. That's the entire motivation for an RNN.

🧠 The missing-word detective

Read this sentence one piece at a time. What should the final word be?

The
Word 1 of 8
Everyday analogy: Imagine hearing a conversation one word at a time. You keep a mental note of what people have said so the next word makes sense.
Without memory

Ordinary feedforward network

current word→prediction

In its basic form, it treats each input independently unless you explicitly package earlier context into the input.

With memory

Recurrent Neural Network

word now+memory→prediction

It carries a hidden state forward: a learned numeric summary of earlier inputs.

Where sequences appear in real life

💬 Language

Word order changes meaning: “not good” differs from “good”.

📈 Sensors

Ten readings reveal a trend that one reading cannot.

🎵 Music

The next sound depends on a melody's earlier notes.

Memory does not mean storing the entire past word-for-word. An RNN compresses what it has seen into numbers; some information may be lost.

MISSION 02 / THE CORE IDEA

The RNN cell: one tiny memory machine

At each step, the cell receives the current input and the previous hidden state, then produces an updated hidden state.

Meet the three symbols

📥 xₜ — Input now

The current word, sensor reading, audio frame, or numerical feature vector.

🧠 hₜ₋₁ — Previous memory

What the RNN carried forward from the previous step.

✨ hₜ — New memory

The new learned summary, passed to the next time step.

The same RNN cell logic (the same trainable weights) is reused at every time step. It doesn't build an entirely new network for each word.

MISSION 06 / HOW RNNs LEARN

Training & Backpropagation Through Time

RNNs don't come with perfect memory rules. They learn from examples by adjusting shared weights to reduce prediction errors.

Training loop in plain English

1. Forward pass

Read the sequence from left to right, updating hidden states and generating predictions.

2. Compute loss

Compare predictions with correct labels. Loss is a number that summarizes how wrong the predictions are.

3. Backprop through time

Trace how shared weights affected loss through the unrolled steps, using gradients.

4. Update weights

An optimizer changes weights slightly. Repeat over many sequences and training iterations.

Each copy in this diagram contributes to gradients for the same underlying recurrent weights. BPTT can be truncated to a shorter number of steps in practical training.

MISSION 07 / WHEN MEMORY FADES

Vanishing & exploding gradients

In a simple RNN, learning a connection across many time steps can be hard because gradients may shrink or grow as they pass repeatedly through the recurrent computation.

📉 Gradient journey simulator

Imagine a gradient getting multiplied by the same factor at each step backwards. Change the factor and the number of steps.

Relative gradient magnitude (toy model)0.0138
Vanishing gradient

📉 Vanishing

Gradient becomes tiny, so early events may contribute very little to updates.

📈 Exploding

Gradient becomes huge, causing unstable updates and sometimes numerical overflow.

🛠 Mitigations

LSTM/GRU gating, gradient clipping (especially exploding gradients), architecture and initialization choices.

This slider uses a simple repeated multiplier, not a full RNN derivative. Real behavior depends on weight matrices, activation derivatives, and the complete computational path.
