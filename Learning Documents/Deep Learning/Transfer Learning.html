Module 01 · The idea

What if AI could reuse what it already knows?

Imagine you want to build an AI that distinguishes good and defective machine parts. You have only 500 labeled photos.

Option A

Start from scratch

Use a new neural network with randomly initialized weights. It must learn useful image patterns using your limited dataset.

Often needs more data and training.

Option B

Transfer learning

Reuse a network already trained on a large image dataset, then adapt it to your machine parts.

Often a stronger starting point.

The one-sentence definition: Transfer learning is a technique where knowledge learned from one task helps a model learn another, related task.

Module 02 · Foundation

How does a deep learning model recognize an image?

A neural network starts with numbers (pixels), passes them through layers, and produces a prediction.

Conceptual example: actual CNN architectures and representations are more complex.

Step 1 · Images become numbers

A color image is represented as a grid of pixel values, often with red, green, and blue channels. The neural network receives this numerical array (a tensor).

Words you will hear

Neuron: a computational unit combining inputs, weights, and an activation.

Layer: a stage that transforms input values.

Weight: a learned parameter of a network.

Loss: a measure of prediction error used for training.

Backpropagation: a way to calculate gradients for updating parameters.

Key connection: Transfer learning reuses weights learned during previous deep learning training.

Don't mix these up

ImageNet

The labeled images used for training and benchmarking.

CNN

A family of neural network architectures suited to image processing.

ResNet50

A particular CNN architecture.

ResNet50 + ImageNet weights

The ResNet50 architecture loaded with previously learned parameters.

The model doesn't memorize every image like a photo album. Training adjusts weights to capture statistical patterns that help make predictions.

What do the controls change?

Replace head: Swap the final classifier so the output matches your new labels.

Freeze: Keep pretrained weights unchanged during training.

Unfreeze: Permit gradient-based updates to those parameters.

Fine-tune: Adapt some or all pretrained layers, usually with a conservative learning rate.

Try it: Select the two-class head and freeze all backbone layers. That is a standard feature-extraction setup.

Understanding the metrics

Epoch: One full pass through the training dataset.

Training accuracy: Percentage classified correctly on examples used to fit the model.

Validation accuracy: Performance on separate examples not used for weight updates.

Overfitting: The model fits the training data well but performs poorly on new examples.

Important: More epochs don't automatically improve validation performance. Real curves can be noisy and depend on architecture, preprocessing, data, regularization, and optimization.
Module 06 · Choose wisely

Transfer learning vs training from scratch

No single training strategy wins in every situation. The best choice depends on data, compute, and similarity between tasks.

Scenario explorer

A robust real-world workflow: Start with a pretrained backbone and new classifier, measure validation performance, then consider unfreezing layers and tuning hyperparameters. Reserve a separate test set for final evaluation.

Common mistakes

  • Thinking ImageNet is a pretrained model.
  • Assuming a classifier trained on 1,000 ImageNet labels can directly output your new labels.
  • Assuming frozen layers continue learning.
  • Comparing methods only on training accuracy.
  • Assuming transfer learning always performs better.
  • Using test data repeatedly to choose hyperparameters.

Quick glossary

Transfer learning

Reuse knowledge from a previously learned task.

Pretrained model

An architecture loaded with weights learned in earlier training.

Backbone

The feature-extracting part of a network.

Classification head

The final layers mapping features to target classes.

Feature extraction

Freeze the backbone and train a new head.

Fine-tuning

Continue training some or all pretrained layers.
