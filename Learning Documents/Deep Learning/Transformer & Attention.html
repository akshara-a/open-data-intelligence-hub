Level 1 · The big idea

What is a Transformer?

A transformer is a neural-network architecture that processes sequences using attention and other learned operations. It's behind many modern language models and is also useful in vision, audio, and more.

📚

Imagine reading a story

When you reach “she,” you recall which character the story was discussing. You connect clues across words.

🧠

Imagine a transformer

Each token has a numerical representation. Attention lets it use representations from other allowed positions.

It's called a transformer because it repeatedly transforms a collection of token representations into new, context-aware representations.

The big journey

“The cat slept”Input text
↓
[The] [cat] [slept]Tokens → embeddings + position information
↓
Attention + feed-forward layersRepeated in transformer blocks
↓
Context-rich token representationsCan power prediction, classification, translation, etc.

Why not just read one word at a time?

Older recurrent networks carried information through sequential hidden states. Transformers use attention to create more direct connections between positions. For a non-causal encoder, all input positions can attend to each other in a layer. For a GPT-like decoder, each position can attend only to itself and earlier positions.

🌐Context

Connect information across a sequence.

⚡Parallel training

Compute many token positions together during training.

🔁Stackable blocks

Repeated layers learn progressively useful representations.

Level 2 · From words to numbers

Tokens, embeddings, and positions

Computers don't naturally understand words. A model starts by turning text into tokens and then into numerical vectors.

1
Tokenization

Split text into pieces. A token might be a full word, part of a word, punctuation, or another unit. Different tokenizers split text differently.

2
Token IDs

Map each token to a number in the tokenizer vocabulary. The number is an identifier, not a meaningful coordinate.

3
Embeddings

Look up a learned vector for each token. The many numbers can encode features useful to the model.

4
Position information

Add or incorporate information about token order. Without it, plain self-attention has no inherent notion of order.

🔬 Token microscopeInteractive

This is an illustrative tokenization, not the exact vocabulary or ID assignments of GPT or any named model. The small embedding vectors shown are invented for teaching.

Why position matters

Sentence A
Dogbitesperson
Sentence B
Personbitesdog

Both contain the same three words, but their order changes the meaning. Position information helps the model distinguish them. Transformers can use learned position embeddings, sinusoidal encodings, rotary position embeddings, and other approaches.

Analogy: Token = LEGO piece name. Embedding = numeric description of the piece. Position = where the piece goes. Attention = which other pieces a piece consults.

Three key ideas

👀Query (Q)

What information is this token seeking?

🏷️Key (K)

What kind of information can this token offer for matching?

📦Value (V)

What information will this token contribute?

Library analogy: Query = your research question. Key = each book's catalog description. Value = the information you take from the matching books.

Level 5 · Several perspectives

Multi-head attention

Instead of just one attention calculation, transformers commonly use multiple attention heads. Each head has its own learned projections and may capture different patterns.

🎭 Switch perspectivesInteractive simulation

Example sentence: “The small dog chased the red ball.” Select a head to see different illustrative attention patterns for the query token dog.

Head 1Own Q, K, V
Head 2Own Q, K, V
Head 3Own Q, K, V

The head outputs are concatenated and then linearly projected to produce the multi-head attention output. Heads are not explicitly assigned grammar jobs; such specializations, when present, are learned rather than guaranteed.

Why have more than one?

Imagine three people reviewing the same sentence. One notices local phrases, another notices actions, and another notices relationships. The analogy helps, but real heads learn numerical patterns and are not necessarily cleanly interpretable.

The crucial rule for text generation

What is causal masking?

When predicting the next word, a GPT-like model must not look ahead at future tokens in the sequence. A causal mask prevents each position from attending to later positions.

🚦 Future-word blockerInteractive
Allowed (past/current)Blocked (future)

Encoder-style attention

Typically allows each token to attend to all unpadded input positions, useful for understanding a complete input.

Decoder-only causal attention

Allows each token to attend to itself and earlier tokens, useful for next-token prediction and generation.

Level 6 · Put everything together

Inside a Transformer block

Attention is important, but a transformer is more than attention. It also uses feed-forward networks, residual connections, normalization, and learned parameters.

↓
Masked or unmasked multi-head attentionShare information across allowed positions
↓
Residual connection + normalizationHelp optimization and preserve information
↓
Feed-forward network (MLP)Processes each token representation with learned transformations
↓
Residual connection + normalizationDiagram is conceptual; ordering varies by architecture
↓
Repeat through many blocksMore contextualized representations
This is a conceptual block diagram. Models may use pre-normalization rather than post-normalization, different normalization schemes, gating, and other variations.
🤝Attention

Mixes information between token positions.

🛠️Feed-forward (MLP)

Transforms each position's features using learned layers.

🛣️Residual + norm

Supports stable training and information flow.

How does a model actually learn?

1
Start with text

Training examples provide token sequences.

2
Make a prediction

A causal language model estimates a probability distribution for the next token at each training position.

3
Measure error

A loss function, often cross-entropy, measures how well the predicted distributions match target tokens.

4
Update weights

Backpropagation and an optimizer adjust the learned parameters, including attention projections.

5
Generate tokens

At inference, a decoder-only model takes prior tokens, predicts a distribution for the next token, selects one, and repeats.

Your pocket-sized cheat sheet

Token
A text piece that becomes a token ID.
Embedding
A learned numerical vector representing a token.
Query
The representation used to ask what to attend to.
Key
The representation used to determine a match.
Value
The representation blended into the attention output.
Softmax
Turns attention scores into nonnegative weights that sum to 1.
Mask
Disallows attention to specified positions, such as future tokens.
Multi-head
Several independently projected attention calculations, combined afterward.
