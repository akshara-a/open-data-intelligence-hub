# Student Enrollment Analytics Dashboard

## 📌 Project Overview
This project is a Student Enrollment Analytics system designed to analyze and visualize student enrollment data. It helps in understanding enrollment trends, student distribution, and course-wise statistics using data analysis and visualization techniques.

The goal of this project is to provide meaningful insights from student data and support better decision-making in academic planning.

---

## 🎯 Objectives
- Analyze student enrollment data effectively
- Identify trends in admissions and course selections
- Visualize student and course statistics
- Build an interactive analytics dashboard
- Improve data-driven decision making

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit / Flask (if applicable)
- CSV Dataset
