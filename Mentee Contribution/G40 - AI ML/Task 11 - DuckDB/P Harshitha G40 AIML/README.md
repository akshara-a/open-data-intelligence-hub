# DuckDB Assignment Using Parquet

## Objective

Learn how to query, filter, aggregate, and export Parquet data using DuckDB.

## Technologies Used

- Python
- Pandas
- DuckDB
- PyArrow

## Project Structure

DuckDB-Parquet-Assignment/

├── data/
│ ├── employees.parquet
│ └── high_salary_employees.parquet

├── database/
│ └── company.duckdb

├── duckdb_parquet_assignment.py

├── requirements.txt

├── README.md

└── .gitignore

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
py duckdb_parquet_assignment.py
```

## Features

- Create Parquet files
- Query Parquet using DuckDB
- Filter records
- Perform aggregations
- Group data
- Create DuckDB database
- Export query results
- Bonus SQL queries
