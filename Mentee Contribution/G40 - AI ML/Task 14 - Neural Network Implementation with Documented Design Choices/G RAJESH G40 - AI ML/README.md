# Task 14 - Neural Network Implementation

## Overview

This task implements a Convolutional Neural Network (CNN) for binary image classification.

The model is trained to classify casting images into two categories:

- `def_front` - Defective casting
- `ok_front` - Non-defective casting

The dataset used for this task is the casting defect dataset from Task 13.

## Objective

The objective is to implement a neural network that can automatically identify defective and non-defective casting images.
