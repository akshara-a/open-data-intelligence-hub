## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Telco Customer Churn dataset. The objective is to analyse customer behaviour, identify churn patterns, and provide business recommendations using Python.

## Dataset

- Dataset: Telco Customer Churn
- Format: CSV
- Source: Kaggle

## Technologies Used
