# Customer Churn Prediction using Reusable ML Pipeline

## Project Overview
This project predicts whether a customer will churn using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Streamlit

## Steps
1. Data Loading
2. Data Cleaning
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Prediction
7. Deployment

## Run Project

Train model:

python src/train.py

Evaluate model:

python src/evaluate.py

Run app:

streamlit run app.py
