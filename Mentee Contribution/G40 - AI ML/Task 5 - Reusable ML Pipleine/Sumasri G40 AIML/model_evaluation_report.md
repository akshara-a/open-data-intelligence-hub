# Model Evaluation

The Random Forest Classifier was trained using the customer churn dataset. After training, the model was tested using the test data.

The model performance was evaluated using Accuracy Score, Confusion Matrix, and Classification Report.

- Accuracy Score shows the overall performance of the model.
- Confusion Matrix shows the number of correct and incorrect predictions.
- Precision shows how many predicted churn customers actually churned.
- Recall shows how many actual churn customers were correctly identified.
- F1-Score gives the overall balance between Precision and Recall.

The model performed well in predicting customer churn. It can identify customers who are likely to leave the company. This helps the business take actions such as providing special offers, improving customer service, and reducing customer churn.

Overall, the reusable machine learning pipeline worked successfully and produced reliable prediction results.
