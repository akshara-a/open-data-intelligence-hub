# Predicting E-Commerce Purchase Likelihood Using an Optimized Classification Model

## 📌 Project Overview

This project predicts whether an online customer is likely to make a purchase using Machine Learning classification algorithms. Multiple models were trained, compared, optimized, and interpreted to support data-driven business decisions.

---

## 🎯 Objectives

- Understand customer browsing behavior.
- Predict purchase likelihood.
- Compare multiple classification models.
- Optimize model performance.
- Analyze feature importance.
- Generate business recommendations.

---

## 📂 Dataset

Dataset Name:

Online Shoppers Purchasing Intention Dataset

Target Variable:

Revenue

- FALSE → Customer did not purchase
- TRUE → Customer completed a purchase
