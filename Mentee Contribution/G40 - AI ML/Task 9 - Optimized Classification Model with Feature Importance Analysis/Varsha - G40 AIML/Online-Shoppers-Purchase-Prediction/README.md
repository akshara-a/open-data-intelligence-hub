# Online Shoppers Purchase Prediction

## Project Overview
This project predicts whether an online shopper will make a purchase using machine learning classification models.

## Dataset
Online Shoppers Purchasing Intention Dataset

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
