# Python Parquet Assignment

## Objective

This project demonstrates how to create, save, read, analyze, and filter data using **Pandas** and **Parquet** files in Python.

## Requirements

Install the required libraries:

```bash
pip install pandas pyarrow
```

## Files Included

* `parquet_assignment.py`
* `employees.parquet`
* `high_salary_employees.parquet`

## Tasks Performed

1. Create a Pandas DataFrame with employee data.
2. Save the DataFrame as a Parquet file.
3. Read the Parquet file into a new DataFrame.
4. Filter employees with salary greater than 50000.
5. Calculate the average salary.
6. Count employees by department.
7. Save filtered data into another Parquet file.
8. Read only selected columns (`name` and `salary`).

## How to Run

```bash
python parquet_assignment.py
```

## Expected Output

* All employee records
* Employees earning more than 50000
* Average salary
* Employee count by department

## Learning Outcomes

After completing this assignment, you will be able to:

* Create and manipulate Pandas DataFrames
* Read and write Parquet files
* Perform filtering and aggregation operations
* Save processed data back to Parquet format
