# Python Parquet Assignment

## 📌 Overview

This project demonstrates how to create, save, read, filter, and analyze data using **Python, Pandas, and Parquet files**.

The assignment uses a simple employee dataset containing employee IDs, names, departments, and salaries.

---

## 🎯 Objective

The main objective of this assignment is to learn how to:

- Create a Pandas DataFrame
- Save a DataFrame as a Parquet file
- Read data from a Parquet file
- Perform basic data analysis
- Filter employees based on salary
- Count employees by department
- Save filtered data as another Parquet file
- Read selected columns from a Parquet file

---

## 🛠️ Technologies Used

- Python
- Pandas
- PyArrow
- Parquet
