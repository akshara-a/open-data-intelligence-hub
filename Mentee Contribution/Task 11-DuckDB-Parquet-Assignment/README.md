\# DuckDB Parquet Employee Analysis



\## 📌 Project Overview



This project demonstrates how to create, store, read, filter, analyze, and export employee data using Python, Pandas, PyArrow, and DuckDB.



The project uses Parquet files for efficient data storage and DuckDB for SQL-based data analysis.



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- PyArrow

\- DuckDB

\- Parquet
