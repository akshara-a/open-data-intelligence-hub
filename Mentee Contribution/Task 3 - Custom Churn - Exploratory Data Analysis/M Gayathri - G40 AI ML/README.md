# Customer Churn Prediction System

## Project Description

This project predicts whether a customer is likely to churn using a Logistic Regression machine learning model. The application is built with Python and Streamlit.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit
* Joblib

## Machine Learning Algorithm

* Logistic Regression

## Features

* Data Preprocessing
* Customer Churn Prediction
* Logistic Regression Model
* Confusion Matrix
* ROC Curve
* Streamlit Web Application
