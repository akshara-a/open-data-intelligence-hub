# Project Insights

## Student Performance Analysis

Based on the analysis performed on the student dataset, the following insights were observed:

### 1. Department Distribution

* The CSE (Computer Science Engineering) department has the highest number of students in the dataset.
* ECE, EEE, and MECH departments have comparatively fewer students.

### 2. Gender Distribution

* The dataset contains both male and female students.
* Female students slightly outperform male students in terms of average marks.

### 3. Academic Performance

* The highest mark scored by a student is **95**.
* The lowest mark scored by a student is **65**.
* Most students scored between **70 and 90 marks**, indicating good academic performance.

### 4. Attendance Analysis

* The average attendance percentage of students is approximately **89%**.
* Students with higher attendance generally achieve better academic results.

### 5. Data Quality

* No significant missing values were found in the dataset.
* Duplicate records were successfully identified and removed during preprocessing.

## Conclusion

This analysis demonstrates how Python Pandas can be used for:

* Data loading and preprocessing
* Exploratory Data Analysis (EDA)
* Statistical analysis
* Data visualization
* Insight generation

The project successfully provides meaningful insights into student academic performance and attendance patterns.
