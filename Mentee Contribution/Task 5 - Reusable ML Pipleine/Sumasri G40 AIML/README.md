# Customer Churn Prediction Pipeline

## Objective

Build a reusable machine learning pipeline using scikit-learn.

## Features

- Missing value handling
- OneHotEncoding
- StandardScaler
- RandomForestClassifier
- Model evaluation
- Pipeline saving using joblib

## Train-Test Split

80% Training

20% Testing

## Technologies

- Python
- Pandas
- Scikit-learn
- Joblib
