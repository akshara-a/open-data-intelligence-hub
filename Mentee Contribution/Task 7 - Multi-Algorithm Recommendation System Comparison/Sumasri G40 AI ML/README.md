# Multi-Algorithm Recommendation System Comparison

## Project Overview
This project compares multiple machine learning algorithms for an e-commerce recommendation system.

## Dataset
The dataset contains:
- User ID
- Product ID
- Category
- Price
- Rating
- Purchase history

## Algorithms Used
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. KNN

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## Best Model
Random Forest achieved the best performance among tested algorithms.

## Technologies
- Python
- Pandas
